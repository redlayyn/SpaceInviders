# Space Invaders

Клон Space Invaders на Unity, 2D, один игрок.

## Управление

- A / D или стрелки: движение
- Пробел: выстрел
- R: рестарт

## Настройки в инспекторе

- Попаданий до смерти моба: префаб моба, Health, Max Health
- Очки за моба: префаб моба, Enemy, Score Reward
- Размер сетки, период и шаг спуска: объект EnemyGrid
- Интервал стрельбы мобов: объект EnemyShooter
- Здоровье игрока: объект Player, Health, Max Health

## Запуск

Открыть проект в Unity, открыть сцену Assets/_Project/Scenes/Main и нажать Play.

## Структура

Assets/_Project/Scripts: Core, Player, Enemies, Projectiles, UI, Editor
